# thinking-log

waoon の設計・運用に関する **思考の記録（design note）** を時系列で残す場所。

## ここに置くもの / 置かないもの

- ここは「決定」でも「計画」でもなく、**そこに至る考えの発展と、結晶した再利用可能な概念**を残す。
  Plan（[`outputs/plans/`](../../outputs/plans/) = 何を決めたか）とはレイヤーが違う。
- 各エントリは **その時点のスナップショットとして凍結** する。後から本文を上書きせず、
  続き・更新は**新しいエントリを起こして backlink でつなぐ**（時系列アーカイブ）。
  → この運用自体、「不変な記録は一度書いたら凍結・追記でつなぐ」という
  [情報の性質と置き場所の棲み分け](2026-07-06-information-properties-and-placement.md) の実践。
  そのため **evergreen 原則（現在形で書く・履歴を残さない）の対象外**の特別区。
- ファイル名は `YYYY-MM-DD-<内容が推測できる slug>.md`。
